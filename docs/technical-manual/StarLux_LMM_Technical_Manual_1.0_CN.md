# StarLux LMM 技术手册

手册 1.0 正式版 | 插件 1.1.8 | 中文版

发布日期：2026-09-14。本文解释公开版本的实际实现，供用户复盘、开发者维护及数据接口移植参考。

源码基线：GitHub 提交 `6a1c62ab433a764afecb14e98fb7f1b4b91f548e`。手册版本与插件版本独立编号；本文不是插件 1.0 的说明，也不包含尚未发布的 1.1.9 实现。

仅用于模拟飞行。评级是本项目的复盘规则，不是航空公司批准的训练标准，也不能代替机型手册、真实飞机检查或适航判断。

## 02 数据契约与采样层

主脚本通过 XPLM 句柄读取基础 DataRef；可选数组通道兼容 FlyWithLua 数据表与直接 XPLM 数组读取。句柄复用，不在每帧重新注册一批全局 DataRef。

| 名称 | DataRef | 在本实现中的用途 |
| --- | --- | --- |
| 物理垂速 | `sim/flightmodel/position/local_vy` | m/s，向上为正；下降为负 |
| VVI | `sim/flightmodel/position/vh_ind_fpm` | fpm，垂速候选及报告对照 |
| 地形 AGL | `sim/flightmodel/position/y_agl` | m；触发、几何锚点及后备高度 |
| MSL 高度 | `sim/flightmodel/position/elevation` | m；与机场标高建立轨迹参考 |
| 接地状态 | `sim/flightmodel/failures/onground_any` | 任意接地点接地标志，不区分主轮、前轮 |
| 法向载荷 | `sim/flightmodel/forces/g_nrml` | 原始 G，再按俯仰及横滚作投影 |
| 姿态 | `sim/flightmodel/position/theta`、`phi`、`alpha` | 俯仰、横滚、迎角，deg |
| 位置与运动 | `sim/flightmodel/position/latitude`、`longitude`、`local_vx`、`local_vz`、`groundspeed` | 经纬度、水平速度及地速 |
| 时间 | `sim/time/total_running_time_sec` | 事件、窗口及分帧作业时钟；不可用时回退 `os.clock()` |
| 帧周期、回放 | `sim/time/framerate_period`、`sim/time/is_in_replay` | 索引预算与回放抑制 |

上述同目录简写只省略表格中重复前缀；移植时必须核对完整名称。IAS/TAS、风速风向、磁航向、降水与跑道摩擦字段也用于报告上下文；它们不是新的评分输入。风为模拟器对应指示字段，不是沿进近路径重建的三维风场。

三个采样层不能混为一谈：核心接地环形缓冲为每次帧回调采样，容量 256；轨迹和操纵目标间隔 0.10 s，容量 720；展示轨迹再聚合为 0.25 s，最多 320 桶。帧率降低时不会补造漏掉的真实样本，实际采样率可能低于目标值。

文中“RA”沿用界面命名，但触发代码的 `radio_alt_ft` 实际来自 `y_agl` 换算，不直接读取驾驶舱无线电高度表，也不保证等于轮胎离地高度。轨迹显示高度又可能改用机场 MSL 参考，详见第 06 节。

重要限制：可选操纵与动力通道有有效性标志，可以输出 N/A；基础读取函数在句柄缺失时可能返回 0，并记录缺失接口。不能把“所有缺失值都不会变成零”当成当前保证。基础接地、时间或高度接口异常时，应将整次测量视为需要排查，而不是把零值当作真实飞行状态。

单位常量：`1 m/s = 196.850394 fpm`；`1 m = 3.28084 ft`；`1 m/s = 1.943844 kt`；`g = 9.80665 m/s²`。FPM 负号保留下降方向，评级使用其绝对值。

来源：[S1 数据接口与缓冲](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L169)。

## 03 事件生命周期与时间基准

| 阶段 | 条件与行为 |
| --- | --- |
| 待命 | 离地、地形 AGL > 20 ft、GS > 50 kt，且没有正在监测的弹跳，才布防 |
| 进近快照 | 已布防、离地且低于 500 ft，更新接地前姿态、风与速度快照 |
| 轨迹准备 | 双垂速确认下降，进入约 140 ft 的预缓冲区，启动轨迹与操纵采集 |
| 首次接地 t0 | 前帧离地、当前接地、已布防、GS > 35 kt；冻结时间、机型、位置和地速向量 |
| 首次压缩捕获 | 记录 t0 后垂速及 G，等待稳定、向上反转或 1.2 s 超时 |
| 分阶段分析 | 计算 FPM、G 与闭合诊断，再等待延长轨迹结束、计算拉平特征 |
| 完成 tf | 更新评级及显示缓存，安排延后上下文和日志作业 |
| 延后作业 | tf + 3 s 起处理机场上下文；tf + 8 s 起尝试生成报告，可等待跑道作业预算 |

这里的 3 s 和 8 s 从 `finalize_landing_analysis(now)` 调度时刻 tf 起算，不是严格从 t0 起算。日志还受匹配超时与分块写盘影响。因此“接地后第 8 秒必定生成文件”不是当前实现的承诺。

核心 256 样本缓冲在已布防且 AGL 不超过 120 ft、首次压缩捕获、弹跳监测或第二次接触捕获期间更新。它存储的是最近若干帧，不是固定秒数。极高帧率下保留的历史时间可能不足以覆盖所有诊断窗口；极低帧率下窗口内样本数量不足。

首次压缩结束规则：垂速 > 0.05 m/s 即认为出现向上反转；否则垂速 >= -0.05 m/s 连续 3 帧，压缩末端定位到这 3 帧中的首帧；否则最迟 t0 + 1.2 s 截止。冲量起点可包含 t0 前最多 50 ms 的最后一个离地帧；固定 G 窗口仍严格从 t0 开始。

回放模式进入和退出会清理布防、分析、轨迹、弹跳及待处理状态，避免把回放当作新的落地记录。当前代码没有对所有暂停、时间跳变、飞机位置跳转组合提供完整的断段证明；这类测试应单独记录并验证。

弹窗可选择分析后立即显示、GS <= 30 kt 显示、接地且 GS <= 1 kt 持续 10 s 后显示、不自动显示或纯净模式。弹窗出现时间不等于采样时间，也不代表所有机场字段已经就绪。

来源：[S1 主循环](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L9197)、[分析状态机](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L8720)。

## 04 最终下降率：候选、几何锚点与降级

### 4.1 三类候选

物理短窗：取 `[t0 - 0.10, t0]` 内离地帧的 `local_vy` 中位数，至少 3 样本。短窗不足时，改取末端窗口中的物理垂速 P25，同样至少 3 样本。

末端窗口统一为 `[t0 - 0.25, t0 - 0.04]`，且只接受离地、地形 AGL 在 0 至 5 ft 的样本。VVI 候选取这个末端窗口的中位数；样本不足时保存进近快照 VVI，标记为非有效候选，留作最后后备。

AGL 几何锚点：在末端窗口中收集最多 64 样本，至少 4 个、时间跨度至少 0.16 s。对时间间距 >= 0.035 s 的所有样本对计算 `(h_j - h_i) / (t_j - t_i)`，至少有 3 对；取斜率中位数，接受 -20 至 +3 m/s 的结果。它是 Theil-Sen 型稳健趋势估计，不是驾驶舱 VVI 的复写。

### 4.2 选择规则

| 顺序 | 有效 AGL 锚点存在时 |
| --- | --- |
| 1 | 物理候选有效、与 AGL 差 <= 30 fpm，且不比 VVI 更远：选物理 |
| 2 | 否则，VVI 有效且与 AGL 差 <= 30 fpm：选 VVI |
| 3 | 两者均不满足：直接选 AGL 趋势 |

物理与 VVI 到 AGL 的距离相等时优先物理。没有有效 AGL 时，依次选有效物理、有效 VVI、进近快照 VVI。30 fpm 是本项目的选择门槛，不是已证明的测量误差上限。

结果先四舍五入到整数 fpm，半值远离零，再进入评级。冲量复核的接地前垂速则沿用所选来源的未取整值；不要使用报告里已取整的 FPM 去期待完全一致的冲量结果。

### 4.3 可手算示例

以下是合成算例，不是实飞或用户日志：物理 -104 fpm、VVI -65 fpm、AGL -63 fpm，且三者都有效。差值分别为 41 与 2 fpm，应选 VVI -65 fpm。若物理 -70、VVI -56、AGL -63，则两者均差 7，选物理 -70。

P25/P75 使用排序后第 `ceil(N * p)` 个值，索引从 1 开始，不作线性插值。普通中位数在偶数样本时取中间两个值的均值。外部重算时使用不同百分位定义，会产生数值差异。

AGL 趋势会受地形变化、机体参考点、起落架姿态与帧率影响；它是候选间的几何参照，不是独立高精度传感器。接地标志同样不是主起落架接触力的专用开关。

来源：[S1 垂速分析](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L4940)。

## 05 G 值：固定窗口与物理闭合复核

### 5.1 原始 G 与投影

原始 `g_nrml` 只接受 `0.2 < G <= 5.0`；其余样本不参与有效 G 统计。每帧近似垂直投影：

`Gv = G_normal * cos(pitch) * cos(roll)`，角度先转弧度。

这只是法向载荷的姿态投影，未加入完整机体三轴载荷向量，不能等同于严格的地轴总垂直加速度，也不是起落架载荷传感器。报告中原始接地 G、轨迹桶 G、最终 G 不是同一种统计量。

### 5.2 最终值主链

固定窗口为 `[t0, min(压缩末端, t0 + 0.160 s)]`。至少 5 个有效样本且首末跨度 >= 0.040 s，才使用这个窗口的 P75。窗口可能被较早的压缩结束截短，“160 ms”并不意味着每次均记录了完整 160 ms。

固定窗口不足时，使用首次压缩全段的 Gv P75。全段也必须满足至少 3 个有效样本、最大相邻有效样本间隔 <= 0.050 s。若全段质量不满足，最终值改用全段 P75 与 FPM 后备上限中的较小者。没有可用全段 P75 时，代码使用接地 G 后备。

`Gcap = 1 + |FPM_integer| * 0.00508 / (0.42 * 9.80665) + margin`

margin：|FPM| <= 100 时 0.08；<= 250 时 0.12；<= 300 时 0.16；更大时 0.22。最终结果限制在 1 至 5 G。这是低质量样本的保护性估计，不是测得的冲击峰值。

### 5.3 冲量诊断，不参与加权融合

接地后速度取 `[max(t0, end_time - 0.05), end_time]` 内的 `local_vy` 中位数，缺失时后备为 0。`end_time` 是结束确认帧；连续 3 帧稳定时，它晚于回溯到首个稳定帧的 `impact_end_time`。`deltaV = max(0, v_after - v_before)`；`T = max(0.03, impact_end_time - impact_start_time)`。

对相邻有效样本用梯形积分：

`I = sum( ((Gv_i - 1) + (Gv_(i+1) - 1)) / 2 * 9.80665 * dt )`

只积分 `0 < dt <= 0.10 s` 的段，保留低于 1 G 的负贡献。接地前基线 G 仅是诊断值，不替换公式中的 1。最大间隙另用于前述 50 ms 质量门槛。

`error = |I - deltaV| / max(deltaV, 0.20)`；`G_equiv = clamp(1 + deltaV / (9.80665 * T), 1, 5)`。

有效全段条件下，error <= 25% 为 HIGH，<= 60% 为 MEDIUM，更大为 LOW。样本不足也为 LOW，但会启用后备上限。两种 LOW 含义不同：闭合差大但样本有效时，仍保留固定窗/全段 P75，不与等效 G 混合，也不因此触发 FPM 上限保护。

合成示例：固定窗排序样本 `[1.00, 1.08, 1.12, 1.20, 1.34]` 且跨度足够，P75 取第 4 个，即 1.20 G，不是最大值 1.34 G。若 deltaV = 0.5 m/s、I = 0.2 m/s，error 为 60%，归 MEDIUM；它不会改变有效 P75。

来源：[S1 G 清洗与投影](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L4187)、[G 计算](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L5302)。

## 06 延长轨迹、高度校准与拉平指标

### 6.1 记录区间

已布防且离地、参考高度在 0 至 140 ft、物理垂速与 VVI 都 <= -50 fpm 持续 0.20 s，启动预缓冲采样。目标每 0.10 s 一点，下一次采样安排为“当前时间 + 0.10 s”，不会追补遗漏帧。720 个槽位用尽后标记受限，不滚动覆盖，也不是无限长黑匣子。

首次接地前，参考高度升至 >= 150 ft、双垂速 >= +100 fpm 连续 1 s，或采集超过 120 s，会取消当前轨迹。有效拉平分析还要求至少 12 个原始点、至少 4 个聚合桶。

首次接地强制留下锚点，并继续记录；连续接地 >= 2 s 才正常结束。再次离地会重置连续接地计时，最迟 t0 + 8 s 结束。这里是有上限的延长记录，不保证覆盖任意长的弹跳或滑跑。轨迹中的触地计数是接地标志转换次数，不等于经判定的弹跳次数。

### 6.2 高度与时间对齐

若已有可用机场标高，优先用“飞机 MSL 高度 - apt.dat 机场标高”，否则用地形 AGL；轨迹启动后保持所选参考。前者是机场平面参考，不包含完整跑道纵坡。

首次接地时的轨迹参考高度若在 0 至 60 ft，作为机体参考偏移从整条轨迹扣除；不合理时偏移置零。扣除后高度下限为零。取校准后首个 <= 100 ft 的已有采样点作为 T+0，不插值求精准 100 ft 穿越时刻。因此本手册的事件 t0 与图表 T+0 不是同一个零点。

### 6.3 聚合与曲率

按 0.25 s 桶对数据求均值，空桶不补点。FPM 主轨迹沿用最终 FPM 所选物理或 VVI 来源；若最终选 AGL，则通过相邻桶的校准高度差分构建 FPM。接地锚点桶重新定位到 t0、高度 0、FPM 为最终整数值；其 G 为接地瞬时后备值，不保证等于最终稳健 G。

对首次接地以前相邻三桶：`s1 = (f2-f1)/dt1`，`s2 = (f3-f2)/dt2`，`C = (s2-s1)/((dt1+dt2)/2)`，仅接受 dt1、dt2 > 0.10 s。拉平曲率指标为 `P75(|C|)`，单位可理解为 fpm/s²。它是垂速曲线的二阶时间差分，不是飞机轨迹的几何曲率，也不是能量曲线。

净改善量为接地 FPM 减入口 FPM；单调效率为正改善量除以 `max(总绝对变化量, 1)`；下降加重比例统计相邻 FPM 变化 < -20 的比例。方向翻转忽略绝对变化不超过 20 fpm 的小变化；翻转 >= 5，或 >= 3 且效率 < 0.55 / 加重比例 >= 0.40，会触发较强振荡描述。70% 时段后的恢复比例也用于复盘。

这些描述不参与 NICE/STABLE/ATTENTION/UNSTABLE 评分，不能直接推断驾驶员技巧或某机型的合格拉平标准。

来源：[S1 高度参考](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L3571)、[轨迹与拉平分析](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L4433)。

## 07 弹跳、评级与中心线修正

### 7.1 基础评级

| 等级 | FPM 绝对值上限 | G 上限 |
| --- | --- | --- |
| NICE / 轻柔 | 100 fpm | 1.20 |
| STABLE / 稳定 | 250 fpm | 1.50 |
| ATTENTION / 需注意 | 300 fpm | 1.80 |
| UNSTABLE / 不良 | 超过 300 | 超过 1.80 |

分别按 FPM 和 G 分档，取较严重者，不求均值。边界等于上限时仍属于该档。FPM 已先取整，G 比较内部数值，不应由显示时的两位小数反推边界。例如 -299 fpm / 1.24 G 为 ATTENTION，不是 STABLE；-100 / 1.20 为 NICE；-101 / 1.20 为 STABLE。

`classify_landing` 保留外部等级提示参数，可将等级提升到更严重档，但当前不是可配置的航空公司标准引擎。默认阈值属于项目规则。

### 7.2 弹跳判定

首次接地后启动最长 6 s 的候选监测。再次离地后返回地面，须离地持续 >= 0.12 s，且期间峰值地形 AGL >= 0.5 ft 或峰值向上垂速 >= 0.15 m/s，才确认弹跳。AGL 门槛用原始地形参考，不是已经清零的轨迹高度。

确认后对第二次接触采集 0.35 s，G 取这段投影值 P75；第二次 FPM 取此前 0.25 s 离地物理垂速 P25，不复用首次接触的三候选选择链。第二次 G 捕获一旦开始，可以在候选监测期限后结束。轨迹正常结束且没有已确认弹跳时，也可能提前结束候选监测，因此并非每次都完整监测 6 s。

当前评级链只处理一次确认的二次接触。弹跳将 NICE 降为 STABLE、STABLE 降为 ATTENTION，ATTENTION 保持；原本 UNSTABLE，或首次最终 G / 第二次 P75 G > 1.80，则为 UNSTABLE。第二次 FPM 保留复核，不独立重走基础 FPM 分档。

### 7.3 中心线修正

仅在成功匹配跑道后应用一次：偏离绝对值 <= 7 m 不变；> 7 且 <= 15 m 时在非红等级中降一级，最高到 ATTENTION；> 15 m 为 UNSTABLE。它使用飞机接地位置到中心线的距离，不是某个轮胎位置。

中心线与弹跳是两项独立的一次性修正，可以叠加。合成示例：基础 NICE，确认弹跳后 STABLE，再有 8 m 偏离则 ATTENTION；仅 7 m 不降级，15 m 仍走降一级规则，15.1 m 直接 UNSTABLE。迟到的跑道结果可能使初始弹窗等级更新；分析器按最终报告复盘。

## 08 机场候选与跑道几何匹配

预取在已布防、离地、AGL 100 至 5000 ft、物理垂速 < -0.1 m/s、GS > 50 kt 时检查，间隔 5 s。主机场导航候选限 40 km；附近探测使用 5 km 半径上的 8 个位置，保留距飞机 15 km 内的机场，移动 2 km 或经过 30 s 才重新探测。预取队列常规上限 12，优先插入不应理解为严格内存硬限。

接地后用冻结的接地点寻找 15 km 内机场导航候选，再读取 apt.dat 几何并比较可用缓存候选。当前入口若找不到这个近邻导航候选会提前返回，不能保证仅凭已有几何缓存就总能救回机场。没有读取 FMS 目的地或 SimBrief。

地景来源按 `scenery_packs.ini` 的启用优先级处理，跳过禁用包，并处理 Global Airports。读取陆地跑道 100 行的端点、宽度、位移入口及相关标记；不支持以水跑道 101 或直升机坪 102 行完成同样的跑道匹配。

### 8.1 几何计算

在接地点附近建立局部东/北平面，地球半径取 6,371,000 m，经度距离乘纬度余弦。水平运动方向由 `(local_vx, -local_vz)` 归一化，速度至少 2 m/s；不使用磁航向猜测跑道编号。

令 u 为端点 1 指向端点 2 的单位向量，p 为端点 1 到接地点的向量，L 为长度。`s = dot(p,u)`；`c = u_e*p_n - u_n*p_e`；`a = abs(dot(u, velocity_unit))`。

有效候选要求：L >= 100 m、宽度 > 0、`|c| <= width/2 + 45 m`、`-150 <= s <= L+150 m`、a >= 0.35。比较分数：

`score = |c| + 4 * max(0, -s, s-L) + 220 * (1-a)`，越小越优。

同机场另一条不同跑道，或其他已比较机场，与最佳分数差 < 25 时视为歧义并拒绝匹配。这个分数不是概率；候选集合不完整时，单一最佳候选也不意味着全世界范围唯一。

### 8.2 输出解释

根据运动方向选择跑道端，编号及 L/R/C 来自 apt.dat。入口后距离按 s 或 L-s，再扣对应端位移入口；剩余距离到物理远端，不能当作公布 LDA 或刹车性能计算的可用距离。

接地点在物理长度范围内、`|c| <= width/2 + 8 m` 且 a >= 0.75，标记 HIGH；其他被接受结果为 MEDIUM。这是几何匹配等级，不是具有统计置信区间的精度认证。允许一定跑道外容差是识别策略，不意味着该接地位置符合操作要求。

预取几何不直接改变评分；最终匹配成功后才应用中心线规则。关闭精确识别或匹配失败时保留失败状态和核心落地数据，不用磁航向补造跑道。

来源：[S1 来源与预取](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L2139)、[跑道解析和匹配](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L3186)。

## 09 持久索引、增量更新与性能预算

缓存文件名仍为 `LMM_Apt_Index_v1.cache`，但内部格式版本已是 2，不要由文件名推断格式。它存储按来源分片的机场标识与 apt.dat 字节偏移，不复制所有地景，也不是完整全球跑道几何数据库。

启动发现来源后，检查文件大小及轻量内容指纹：在起始、25%、50%、75% 和末尾附近各读 1024 字节，计算滚动校验。未变来源复用索引；新增或改变来源重建对应分片；删除、禁用或优先级变化重组有效来源。版本 2 还保存进度，支持断点与约 30 s 检查点。

这是降低重复扫描成本的折中，不是完整文件哈希。相同大小文件若只修改探针之外的内容，存在漏检风险。排查地景替换后异常时，应在退出 XP 后保留备份并重新生成缓存，不能宣称缓存永不失效。

后台建库仅在安全状态推进，例如地面 GS <= 5 kt，或 AGL >= 6000 ft 且 |垂速| <= 3 m/s。正在精确扫描、落地分析、弹跳或待写报告时会让出预算。首次初始化因此可能等待合适飞行阶段，而不是加载脚本后一直满速扫描。

| 平滑 FPS 档位 | 每次读取 64 KiB 块数 | 最短推进间隔 |
| --- | --- | --- |
| < 20 | 1 | 0.40 s |
| 20 至 < 30 | 1 | 0.15 s |
| 30 至 < 45 | 2 | 0.10 s |
| 45 至 < 60 | 3 | 0.075 s |
| >= 60 | 4 | 0.05 s |

FPS 输入由帧周期倒数得到并限制在 5 至 240；首次平滑值不超过 30，降帧时平滑系数 0.25、升帧时 0.06，以便更快退让、更慢增加负担。最高每次 256 KiB，是字节/调度预算，不是 CPU 耗时硬上限，也不保证对每台电脑零影响。

缓存保存分批最多处理 2048 行，通过临时文件、备份和 END 完整性标记替换。初始化显示百分比表示工作进度，不是准确剩余秒数；内存索引完成与缓存最终写盘完成也不完全同一时刻。

机场精确解析是另一条分帧作业，常规读取块为 128 KiB；预取最长 300 s，落地解析预算 30 s。报告调度的独立跑道截止时间从上下文计划时刻起算。低 FPS、慢盘、大量来源仍可能使解析超时；失败应显式报告，不能无限阻塞落地记录。

来源：[S1 索引参数与状态](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L1376)、[缓存处理](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L2282)。

## 10 操纵输入与舵面响应

每轴按以下顺序收集候选，再用整段采样中的活动程度选择。原始值绝对值 <= 1.5 才接受，随后限制到 [-1,1]。合法零输入保留为零，不作为缺失标志。

| 轴 | 第一候选 | 第二候选 | 第三候选 |
| --- | --- | --- | --- |
| Pitch | `sim/joystick/yoke_pitch_ratio` | `sim/cockpit2/controls/yoke_pitch_ratio` | `sim/joystick/FC_ptch` |
| Roll | `sim/joystick/yoke_roll_ratio` | `sim/cockpit2/controls/yoke_roll_ratio` | `sim/joystick/FC_roll` |
| Yaw | `sim/joystick/yoke_heading_ratio` | `sim/cockpit2/controls/yoke_heading_ratio` | `sim/joystick/FC_hdng` |

活动条件满足任意一项即可：范围 >= 0.006、累计相邻绝对变化 >= 0.02、最大绝对值 >= 0.02。依优先级选首个活动候选；都不活动则选首个可用候选。常值非零也可被识别为活动，避免漏掉稳定保持的输入。

这解决了部分机模主接口不动、后备接口有响应的问题，但属于启发式选择；FC 通道可能含飞控处理，并不等于 USB 杆位。用户手柄、自动驾驶、飞控指令和物理舵面不能未经验证就视为同一信号。

舵面读取 `sim/flightmodel2/wing/` 下的 `elevator1_deg` 索引 8/9、`aileron1_deg` 索引 0/1、`rudder1_deg` 索引 10/11，保留角度和原始符号。这是当前通用翼面索引假设，不保证适配所有自定义机模的网格动画或真实舵面组合。

数组优先使用 FlyWithLua 的零基数据表；直接 XPLM 读取会从 0 读到目标索引并兼容返回表索引形式。接口可读不代表 ENG2 或某片舵面物理映射已经自动验证，仍需左右单独动作测试。

轨迹内操纵目标采样间隔约 100 ms，因此适合观察整体输入与响应趋势，不具备可靠量化亚 100 ms 延迟的条件。面板俯仰轴的视觉翻转用于对应推杆/拉杆，不改变原始日志符号。

来源：[S1 可选接口与选源](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L228)。

## 11 发动机、油门与机模适配

机型上下文在新轨迹开始时刷新，支持同一 XP 会话切换飞机。`sim/aircraft/engine/acf_num_engines` 读取的数量会被限制，当前记录最多 4 台发动机；分析器预留更多列的解析能力，不等于采集端已经记录超过 4 台。

### 11.1 N1 来源优先级

| 机模家族 | 1.1.8 已实现的专用来源 | 不可用时 |
| --- | --- | --- |
| FlightFactor 匹配家族 | `1-sim/eng/N1/L`、`1-sim/eng/N1/R` | 通用链 |
| Zibo / LevelUp | `laminar/B738/engine/indicators/N1_percent_1`、`N1_percent_2`（同前缀） | 通用链 |
| ini A300 | `A300/engine/engine1_N1`、`A300/engine/engine2_N1` | 通用链 |
| Rotate MD-11 | `Rotate/aircraft/systems/eng_n1` 数组 | 通用链 |
| ToLiss | 没有单独实现专用 N1 提供器 | 通用链 |
| 其他或未匹配机模 | 无已选专用提供器 | 通用链 |

这里列的是公开源码实现的探测路径，不代表每个厂商所有机型、版本均已验证。机模识别字符串/ICAO 与所需句柄同时满足，才能选择对应提供器；仍须用实际仪表核对。

通用链依次为 `sim/cockpit2/engine/indicators/N1_percent`、`sim/flightmodel/engine/ENGN_N1_`。每台发动机每个采样检查 0 至 200 的有效范围，专用值失效可降级到通用值；仍无有效值则缺失。这个宽范围只排除明显异常，不能识别“读得到但与驾驶舱不一致”的情况。

报告记录本段用过的来源集合，尚不是逐采样、逐发动机的完整来源谱系。不要用固定比例把通用 N1 强行换算为驾驶舱 N1，也不要把 N1 百分比当作推力百分比。

### 11.2 油门和空客卡位

读取 `sim/cockpit2/engine/actuators/` 下的 `throttle_ratio`、`throttle_jet_rev_ratio`、`throttle_beta_rev_ratio`；按 `acf_en_type` 选择前向、反推或 Beta 范围。类型 5/7 优先喷气反推轴，类型 0/1/9/10 优先 Beta/反推轴；保留负值，不能统一剪裁到 0 至 1。

当前 ToLiss 专用分支使用 `AirbusFBW/throttle_input` 和 `AirbusFBW/THRLeverMode`。家族外观判断可以识别空客式轴，但可靠卡位仍依赖专用数据，不是所有 Airbus ICAO 都自动有可用卡位。

杠杆值判定优先顺序：< -0.001 为 REV；绝对值 <= 0.015 为 IDLE；>= 0.97 为 TOGA；0.80 至 0.93 为 FLX/MCT；0.62 至 0.75 为 CL；其余为 MANUAL；无有效值为 N/A。这是实现中的范围映射，不是某机模对外承诺的卡位规范。

### 11.3 “动力类型”不等于“能量状态”

分析器可解析 N1、EPR、螺旋桨及扭矩类型并使用相应刻度，但 1.1.8 Lua 的当前通用采集输出仍以 N1 为主，没有实现覆盖所有机模的 EPR/螺旋桨/扭矩自动采集链。可显示的格式能力不能写成已实装的数据能力。

油门杆、N1、EPR、功率与飞机总能量各有物理含义，不能直接混成无量纲“推力支撑”。当前没有综合能量评分或能量曲线算法，动力通道不影响落地评级。

## 12 TXT 报告、诊断与写盘

报告保存在本地 `LMM_Log`，命名包含机场、机型、跑道、时间和 `_CN` / `_EN`。命名时间是冻结的系统日期时间；分析窗口用运行时间，两者不可互换。报告不是固定字段位置的二进制协议，解析器需识别中英文键名、列标题与缺失值。

| 数据层 | 内容与可复核范围 |
| --- | --- |
| 摘要 | 最终 FPM、G、评级、机型、气象、机场与跑道状态 |
| 诊断字段 | FPM 三候选、选源原因、G 固定窗/全段/等效值、闭合误差与方法 |
| 轨迹表 | 约 0.25 s 聚合数据，含接地锚点及延长记录 |
| 操纵表 | 约 0.10 s 的有效通道值、逐发动机列及来源说明 |
| 可选数学审计 | 首次/第二次接触附近的帧样本和计算过程；受固定缓冲上限约束 |

普通聚合 TXT 不能完整重建原来的每帧 P75、Theil-Sen 斜率集合或冲量积分。需要严格重算时，应提前打开相应数学审计选项，检查样本数量、时间跨度及受限标志；开启 Debug 显示并不意味着自动拥有全部未聚合原始数据。

作业延时见第 03 节。报告文本内容先在一次受保护调用中完整构造，随后每帧最多写 8192 字节；成功关闭文件才提示完成。当前改善主要来自延后和分块写盘，文本构造本身不是协程逐帧生成，不能宣称全过程都有硬耗时预算。

写失败会记日志并继续飞行监测；异常中断可能留下不完整报告。分析器或外部程序应检查所需字段、数据表结束与有效数据量，不能仅凭文件存在判定记录完整。

成功后直接追加内存记录索引，减少重复遍历文件夹。通常只在落地弹窗内闪烁三次“落地报告已生成”；Debug 才在底部显示路径细节。仍在计算的中心线字段可稍后更新，不应以弹窗首次出现时的占位文本作为最终报告。

来源：[S1 报告构建与写入](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L7810)、[分帧作业](https://github.com/Starlux531/StarLux-Landing-Meter/blob/6a1c62ab433a764afecb14e98fb7f1b4b91f548e/StarLux_LMM_v1.1.8.lua#L8335)。

## 13 分析器、UI 与数据解释边界

`LMM_Report_Reader.html` 是插件随带本地分析器。独立的 `Starlux_Analyzer_落地分析器.html` 无需 XP 即可打开，并隔离其浏览器设置空间。读取 TXT 不修改原报告，不将落地记录上传。

主/对比曲线、100 ft 参数、操纵舵面、油门仪表、XYZ 指示与小跑道共享图表时间位置。播放支持最低 0.25 倍及拖动进度；它是已有采样的浏览方式，不是重新计算飞行动力学。没有悬停或播放定位时，中立仪表可能只是待机外观，不应读作真实零输入。

跨单位曲线会各自归一化绘制；同一参数的主/对比共享该参数范围。图中两条不同单位曲线重合，不表示物理量相等。精确值以悬停读数、单位、原始表和选源为准。油门与动力仪表的满量程也不是跨机型的真实推力归一化。

融合模式把操纵曲线合并到 100 ft 图；其中 Pitch/Roll 改为操纵参数，不再代表原来的机体俯仰/横滚角。看曲线前必须确认名称、单位与图例；分离模式便于区分输入和姿态。

小跑道用时间和地速积分等已有量作对齐，不是逐帧经纬度重建的地面航迹。主跑道视图保留匹配几何，但宽度、标记及灯光图形为便于阅读作示意处理；通用 7.5° 俯仰参考线不是具体机型尾擦限制。

RGB 主题、保存预设、横向布局、缩放和融合状态属于显示配置，不更改评分。图线颜色可随背景调整，固定警示语义仍需保留；颜色不能替代等级文字、线型和数值判断。

Standard 使用一个全局中/英文选项控制设置、弹窗、数据库通知、报告和从插件启动的分析器。中文旧报告可在英文分析器中复盘，但原始 TXT、用户自命名预设和未识别自由文本可能仍保持原文。Compatibility 的旧设置/记录控件保留英文；中文报告及标准字号弹窗是保留能力，不应承诺旧版控件具备全部原生中文字号功能。

安装器检查 GitHub/Gitee 发布目录并下载，飞行记录本身不用于更新查询。手册不把下载哈希等同于代码签名；安装与备份边界以发布安装说明为准。

## 14 复核、测试与移植要求

### 14.1 推荐复核顺序

1. 记录 XP、FlyWithLua、LMM 和机模版本；确认只有一个启用的 LMM 主脚本，检查缺失 DataRef 日志。
2. 核对原始接地时间和状态转换，排除回放、瞬移与不连续时间；确认不是拿触地后的截图对比触地前读数。
3. 按第 04 节重算候选和有效性，核对最终来源及整数舍入。
4. 分别核对原始 G、姿态投影、固定窗 P75、全段质量和降级路径，最后看冲量闭合，不把 LOW 自动理解为评级无效。
5. 核对机场来源优先级、冻结位置、地速方向、位移入口与中心线距离，再核对弹跳/中心线修正。
6. 一次只动一个输入轴或发动机油门，比较左右通道、零输入、反推及卡位，并保存对应 TXT。

### 14.2 最小测试矩阵

| 测试 | 应观察的实现行为 |
| --- | --- |
| 无弹跳接地 | 正常继续记录约 2 s；最终结果与接地锚点保留 |
| 短离地抖动 | 不满足持续时间或高度/上升门槛时，不确认为弹跳 |
| 确认二次接触 | 有二次采样和一次评级修正，不无限累计触地惩罚 |
| 低 FPS / 丢帧 | 固定窗或全段质量不足时能看出后备方法 |
| 高 FPS | 检查 256 环形缓冲是否覆盖所需时间窗口 |
| 平行跑道 / 缺失机场 | 歧义或缺候选时保留失败，不补造跑道编号 |
| 新增 / 禁用 / 替换地景 | 未变分片复用，变化分片更新，必要时重建缓存 |
| ENG1 / ENG2 分别操作 | 逐通道数值和来源正确，不以复制 ENG1 填充 ENG2 |
| CN / EN 与两种 UI | 数据算法不变，兼容版语言限制明确 |
| 中断写盘或退出 | 不把残缺文件与未完成缓存误判为完整数据 |

这是建议验证矩阵，不是声称本文已在所有机模与帧率下完成实机测试。本文完成的是公开源码核对、文档数值检查与排版检查；模拟器中的数据准确度仍须由有来源的测试记录验证。

### 14.3 移植不应只替换变量名

新平台必须分别映射接地标志、向上为正的垂速、载荷定义、参考点高度、帧时钟、舵面和发动机通道。保持显式单位、缺失标志、时间戳、统计窗口与来源记录；先用同一组合成样本验证百分位、舍入、边界及降级，再用实测记录校验物理含义。

SDK 或另一模拟器的“G”“AGL”“N1”字段即使同名也未必同义。当前法向投影近似、机模源偏差和 AGL 参考问题不会因为改为 C++/XPL 自动消失。完整三轴载荷、逐样本来源、更多动力类型、严格耗时预算、平台移植及更长航段采集均属于后续可研究项，不是 1.1.8 已承诺的功能。
