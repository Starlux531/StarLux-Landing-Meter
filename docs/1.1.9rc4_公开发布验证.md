# 1.1.9rc4 公开发行验证

2026-09-30。插件 **1.1.9rc4**，安装器 **1.0.3**。

安装器功能继承本地 1.0.2rc4。已公开的安装器 1.0.2 只接受纯数字的安装器发行标签，因此正式使用 `installer-v1.0.3`，让旧安装器能发现自更新。插件维护版本仍为 `v1.1.9rc4`。

## 发布范围

- 插件发行标为 Latest，包含 CN / ASCII EN 完整离线包、Standard / Compatibility 两种 UI 的中英文四种独立载荷、独立分析器、仅安装器包、说明和校验清单。
- 安装器独立发行包含自更新 ZIP 与 `installer-release.json`；不会占用插件 Latest。
- 同步当前运行源码、安装器源码、构建脚本、测试及公开说明。历史发行附件和 README 图集保持。
- 个人设置、飞行记录、诊断包、恢复备份和航空公司参考资料不属于发布内容。

## 发布前验证

- 安装器 1.0.3：71 项自动维护、事务恢复、版本排序及自更新相关测试通过。
- 四种插件载荷各 21 个文件：SHA-256、清单与归档一致性、全部 Lua 语法、语言和 UI 变体差异验证通过。
- 安装器 EXE 产品版本、独立自更新清单及归档校验通过；离线包均内置插件 RC4。
- CN / EN 包对应文件内容一致；EN 文件名及目录名均为 ASCII。
- 插件业务代码延续已验证的 RC4 整合版本；此次公开发布调整通道、发行说明和安装器版本编号。

模拟器内不同机模、图形环境和 Compatibility 实机验证仍需继续；长平飘和拉飘是插件测试阈值，并非航空公司 QAR 标准。
