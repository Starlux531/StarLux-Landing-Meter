StarLux 落地率插件 1.0 正式版使用说明
====================================

一、安装
--------
将以下内容放入：
X-Plane 12/Resources/plugins/FlyWithLua/Scripts/

- StarLux_LMM_v1.0.lua
- LMM_Report_Reader.html
- LMM_Settings.cfg
- LMM_Log 文件夹

如果安装过旧版，请把旧版 StarLux_LMM_*.lua 移出 Scripts，避免两个版本同时运行。
启动 X-Plane，或通过 FlyWithLua 重新加载所有 Lua 脚本。


二、打开设置窗口
----------------
在 X-Plane 菜单中依次打开：
Plugins > FlyWithLua > FlyWithLua Macros > StarLux Landing Meter | Open Settings

也可以在 X-Plane 的键盘或摇杆设置中搜索并绑定命令：
starlux/lmm/open_settings

可用设置：
1. 弹窗时机：分析完成后立刻 / 地速低于 30 kt
2. 显示时长：30 秒 / 60 秒 / 120 秒
3. 屏幕位置：九宫格位置选择
4. 窗口布局：横向 / 竖向
5. 背景透明度：25% / 50% / 100%
6. 详细数学日志：关 / 开
7. 测量调试信息：关 / 开
8. 5 秒预览：检查弹窗位置和样式

所有修改会立即保存到 LMM_Settings.cfg。


三、落地记录与游戏内管理
------------------------
插件会在 Lua 文件同目录使用 LMM_Log 文件夹。
每次有效落地完成后，插件会分阶段完成分析、机场识别和 TXT 写入，
并在游戏内提示“落地详细报告已生成”。

打开记录管理：
Plugins > FlyWithLua > FlyWithLua Macros > StarLux Landing Meter | Landing Records

记录窗口支持：
- 刷新日志索引
- 打开 LMM_Log 文件夹
- 打开任意记录的可视化报告
- 删除选中的记录（需要二次确认）
- 分页查看最近记录

从 Lua 菜单打开记录时，插件会使用同目录下的 LMM_Report_Reader.html，
并自动载入所选 TXT。插件内阅读器与独立阅读器为同一套界面。


四、独立阅读器与数据对比
------------------------
无需启动 X-Plane，直接双击 LMM_Report_Reader.html 即可分析已有数据。

基础操作：
1. 点击“选择落地日志”，或把一份/多份 LMM_*.txt 拖入网页。
2. 左侧列表点击记录主体，可切换主要数据。
3. “下载主要数据 TXT”会下载当前主要记录的原文副本。
4. “清空”只清除浏览器当前内存，不会删除磁盘文件。

对比操作：
1. 点击“选择对比日志”额外载入一份数据；或点击左侧记录右侧的“对比”。
2. 主要数据使用评价色实线；对比数据以低透明度灰色虚线显示。
3. 100 ft 图表会同时标出两份数据各自的 50 ft 参考线。
4. 鼠标在图表上移动时，会显示同一时间附近的主要／对比数据。
5. “交换主／对比”可改变两份数据的角色。
6. “取消对比”只退出对比状态，不会移除已载入记录。

对比面板包含：
- 触地下降率
- 最终载荷
- IAS
- GS
- 100 ft 至触地用时
- 拉平曲率

对比功能不会重新计算或改变日志原有评分。


五、评分标准
------------
Nice 轻柔接地（深蓝色）：FPM ≤ 100，G ≤ 1.20
Stable 稳定扎实落地（深绿色）：FPM ≤ 250，G ≤ 1.50
Attention 需注意（深橙色）：FPM ≤ 300，G ≤ 1.80
UNSTABLE 不良落地（深红色）：FPM > 300，或 G > 1.80

FPM 与 G 分别判断，最终取较严重的等级。
“不良落地”表示数据超出插件当前 Attention 上限，
不等同于真实航空公司的维修检查、事故或适航结论。

若发生弹跳：
- Nice 降为 Stable
- Stable 降为 Attention
- 任一次稳健 G 超过 1.80 时标记为 UNSTABLE


六、数据与算法概览
------------------
记录内容包括：
- 落地时间、总体评价、评价说明
- 机型、落地机场、机场名称与推算跑道
- 触地下降率、VVI 对照值、最终过载
- IAS、TAS、GS
- 迎角、横滚、磁航向
- 风向、风速和相对风
- 道面监测来源与提示
- Bounce Landing 检测
- 100 ft 后拉平轨迹、拉平曲率与轨迹结论
- 本次使用的显示设置

详细数学日志开启时，还会追加可复算的采样表、曲线 G、冲量等效 G、
一致性误差、可信度和最终采用方式。

跑道号根据触地磁航向推算，当前不区分平行跑道的 L/R/C。
只有日志同时包含真实跑道长度和入口距离时，阅读器才绘制跑道触地点。


七、隐私
--------
插件和阅读器不会联网，也不会主动上传飞行数据。
正式发布包不包含作者或测试人员的个人落地日志。
LMM_Viewer.html 与 LMM_Viewer_Data.js 是打开报告时生成的本地临时文件。


八、故障排查
------------
1. 确认 StarLux_LMM_v1.0.lua 与 LMM_Report_Reader.html 位于同一 Scripts 目录。
2. 确认 X-Plane 目录具有写入权限。
3. 查看 X-Plane 12/Log.txt 中以 [StarLux LMM] 开头的信息。
4. 如果脚本进入 Scripts (Quarantine)，请附上 Log.txt 中相关错误进行排查。
