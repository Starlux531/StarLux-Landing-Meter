StarLux 落地率插件 v0.7 使用说明
================================

安装
----
将以下内容放入：
X-Plane 12/Resources/plugins/FlyWithLua/Scripts/

- StarLux_LMM_v0.7.lua
- LMM_Settings.cfg
- LMM_Log 文件夹（内含实飞测试样本，可按需保留或删除）

如果安装过旧版，请移走旧版 Lua 文件，避免两个版本同时运行。

打开设置窗口
------------
在 X-Plane 菜单中依次打开：
Plugins > FlyWithLua > FlyWithLua Macros > StarLux Landing Meter | Open Settings

也可以在 X-Plane 的键盘或摇杆设置中搜索并绑定命令：
starlux/lmm/open_settings

可用设置
--------
1. 落地数据窗口显示时机：触地时 / 地速低于 30 kt 时
2. 显示时长：30 秒 / 60 秒 / 120 秒
3. 屏幕位置：九宫格位置选择
4. 窗口布局：横向 / 竖向
5. 背景透明度：25% / 50% / 100%
6. 测量调试信息：开 / 关
7. 5 秒预览：检查当前弹窗位置和样式

所有修改会立即保存到同目录下的 LMM_Settings.cfg，重新启动后仍然有效。

落地记录
--------
插件加载时会在 Lua 文件同目录创建 LMM_Log 文件夹。
每次有效落地完成约 0.22 秒的 G 值采样和最终评级后显示结果，
并在约 1.5 秒后生成一份独立的 UTF-8 TXT 文件。

记录内容包括：
- 落地时间与总体评价
- 触地垂直速度（FPM）与最终过载（G）
- IAS、TAS、GS
- 迎角、横滚角、磁航向
- 风向、风速和相对风
- 原始 G 值采样明细与评分阈值
- 本次使用的弹窗时机、位置、布局与透明度设置

隐私说明
--------
插件不会联网，也不会主动上传飞行数据。
安装包中的 LMM_Log 内容是作者明确打包的实飞测试样本。

故障排查
--------
如果设置或日志无法保存，请检查 X-Plane 目录的写入权限，并查看：
X-Plane 12/Log.txt
