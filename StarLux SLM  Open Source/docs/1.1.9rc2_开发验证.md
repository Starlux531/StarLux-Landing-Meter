# 1.1.9rc2 开发验证 · 2026-09-25

本次为未公开发布的本地版本；以 beta2 修复为基线。开发前快照：`旧版备份/2026-09-25_beta2_rc2开发前/`。Compatibility 继续暂停公开推送，XP 12.4.3 实机反馈仍待验证。

## 本次改动

- 兼容设置中中文语言选项显示为 `Chinese`。原生中文界面保留中文标签。
- 两份 HTML 分析器在 XYZ 操纵输入旁增加姿态仪，按记录中的实际 Pitch/Roll 绘制，与播放、拖动及悬停共用时间轴。不存在完整姿态样本时显示“无姿态数据”，不把操纵输入当作姿态。
- 姿态仪复用 SVG 元素，更新只改变变换矩阵和读数。保留 200×200 的操纵区及固定 ILS 显示；较窄屏幕自动换行，修复原有窄屏动力/操纵面板媒体规则被覆盖的问题。
- Windows 后台 GitHub 更新检查：仅查询官方仓库发行元数据，按 Standard/Compatibility 附件分别筛选；跳过草稿、预发行及已撤回的 UI 版本。缓存按 UI 版本分开，成功间隔 6 小时，失败 15 分钟后重试。请求超时 15 秒，45 秒后放弃等待结果。其他系统安静跳过。
- 有更新时游戏提示显示 30 秒，设置页保留提示。版本变为最新或可用发行被撤回后清除提示。检查错误不会触发 Lua stopped；不自动下载/安装，也不读取或上传飞行数据。
- 主脚本、报告版本、分析器、清单、包名统一为 `1.1.9rc2`；安装器升至 `1.0.2`，添加本项目维护编号排序。
- GitHub README 保留原有 7 张图，追加用户指定的 2 张截图，展开原折叠图集。提交仅含 README 与两张截图，未公开发布 rc2 插件包。

## 使用

完整本地测试包：`dist/1.1.9rc2/StarLux_LMM_Installer_1.1.9rc2.zip`。退出 X-Plane 后完整解压，使用内置安装器，手动选择 rc2 对应 UI 版本，保留配置安装。此前 1.1.10-beta2 的数字版本高于 1.1.9rc2，需要手动选择，不能依靠旧安装器的“最新”排序。

游戏内更新提示使用 ASCII 英文，以兼容旧版字体；设置页按当前可用语言显示。离线通过不代表 XP 实机验证完成。
