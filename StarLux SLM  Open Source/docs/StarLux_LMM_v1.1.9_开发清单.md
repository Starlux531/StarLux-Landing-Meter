## 2026-09-21 交互修订（当前执行规格）

- 安装器本地维护版 **1.0.1**：旧版 LMM UI 文件、空目录和可确认属于 StarLux 的版本 README 纳入事务备份及清理；保留设置、飞行记录、机场缓存和未知用户文件。1.1.8 及已发布安装器资产保持不变。
- 接地弹窗标准／兼容界面均可拖动，松开后保存归一化位置；选九宫格或复位可回到锚点。
- 取消独立“完整记录 · 进近、滑跑与风”面板。完整记录接入原图表、仪表和播放时间轴，支持 100 ft 聚焦、全程、缩放、横向浏览及播放跟随。主图风参数仅保留风速；风向／迎风／侧风移至落地俯视图旁的可选竖向风图，使用同一时间窗和游标。
- “触地俯视图”叠加真实滑跑路线；“落地俯视图”显示全进近路线、风吹向和同步位置，支持 1–64 倍显式缩放，放大后保留浅色风箭头。延长中线是几何参考，并非实际 LOC 接收信号。
- **删除出口网络判断。接地后在地面且 GS < 30 kt 连续两秒即结束，原因 `low_speed`；无机场网络也能完成。GS ≥ 30、离地、暂停或数据间隙重置计时。** 该状态表示完成低速录制，不代表确认脱离跑道；旧“出口证据＋超过三秒”要求取消。
- 保留已录样本；新增完整段物理 FPM／VVI／AoA 和 `LMM_RUNWAY` 真坐标参考。旧日志缺失字段留空，能可靠对齐的 100 ft 节选提供补充。完整段高度明确标为地形 AGL。新增全程轨迹 FPM 及来源、六个舵面、油门杆与卡位通道；已验证海拔 6000 ft 机场的 AGL 启动及低空载入。
- XYZ 操纵图增加相对机头风吹向及风向／风速读数；Ctrl＋滚轮、缩放按钮或倍率选择是缩放入口，悬停不改变视区和纵轴范围。覆盖层取消固定 20 Hz 限制、按帧刷新并避免重复设置窗口几何；45 项 Lua 离线回归及浏览器交互验证通过，实机流畅度仍待验收。

## 第一批：数据来源与可观察性

先解决输入能否读到、如何验证的问题，再扩展长记录。第一批可交付成果为：统一输入观测、最小摇杆覆盖层、调试源选择器、贴边设置／记录入口。

- [x] **P0.1 基线和数据约定**：运行现有 LuaJIT/UI、网页语法／双语及发行结构检查；约定逐轴值、有效性、来源 ID、原始值、归一化值和时间戳。提前定义后续录制的格式版本、会话 ID、阶段和源切换事件，避免返工。
- [x] **P1.1 输入源适配**：梳理 `LMM_CONTROL_REFS`，建立按俯仰／横滚／方向舵的候选来源与自动／手动选择。复用通用 DataRef；专用机模路径必须来自实际可验证资料或机内诊断，不能臆造 FF777 路径。
- [x] **P1.2 有效性与生命周期**：区分“路径不存在、类型／范围错误、读取失败、有效居中、尚未观察到变化”；零输入不是失效。机模初始化后允许受限频率重试／手动重新探测，换机或插件重载时刷新上下文，避免旧句柄／配置串用。
- [x] **P1.3 统一观测输出**：覆盖层和记录器消费同一来源选择；原始候选值与已选样本分开，替换现有源选择覆盖主候选历史字段的做法。切换仅影响之后的样本，记录事件时间、轴、前后来源、自动／手动模式及原因。
- [ ] **P1.4 最小摇杆组件与调试联动**：正常模式显示摇杆图形；调试模式在同一组件显示来源、DataRef 路径／数组下标、原始与归一化值、可用状态和观察到的变化，提供每轴候选选择及“恢复自动”。先让该组件承担 FF777 诊断，油门／N1 与完整外观编辑在后续批次完成。
- [x] **P1.5 手动选择规则**：只改变读取来源，不写机模操纵值。不可读来源不能伪装成功；手动源失效明确报缺失，自动模式的回退必须留痕。默认本会话有效，可显式保存为机模配置；退出调试隐藏诊断控件但不悄悄改变正在录制的选择，换机重新验证适用性。摇杆输入与舵面／动画数据分开标注。
- [ ] **P1.6 两个贴边快捷按钮**：独立的小按钮分别打开设置、记录栏，复用现有窗口入口；重复点击不创建重复窗口。低透明度、窄占位，悬停／点击时提高可见度，提供中英提示；保留顶部菜单入口。
- [ ] **P1.7 交互与设置**：支持按钮隐藏、左右贴边和透明度设置；默认位置避开现有弹窗，随窗口尺寸／缩放贴边。仅按钮自身命中区域接收点击，外部点击／滚轮不被透明大窗口截获；标准／兼容 UI 均有入口，重载清理窗口和回调。
- [ ] **P1.8 第一批验收**：离线覆盖零值、缺失、越界、逐轴不同源、延迟初始化、切换留痕、重载；实机检查贴边按钮和显示命中区域。FF777 用中立、俯仰、横滚、方向舵动作对照候选读数与导出记录，保存机模／XP／FlyWithLua 版本及来源证据。

完成条件：普通机模读数／录制一致；有效源可切换且过去样本不被改写；两个按钮可靠打开原窗口；FF777 必须有真实输入随动作变化且被正确录入的证据，不能仅因诊断 UI 可用就标记“FF777 已适配”。没有 FF777 运行环境时继续完成通用框架和其他任务，该机模验收单独保持待完成。

## 第二批：连续录制与风序列

依赖 P0.1、P1.1–P1.3；与完整 UI 美化解耦。

- [ ] **P2.1 录制状态机**：进近、接地、弹跳、滑跑、低速完成候选、完成／复飞／中断；2500 ft 暂以地形 AGL 为开发口径，记录来源，不误标为真实无线电高度。低高度载入标记缺失前段。
- [ ] **P2.2 多速率采集**：完整轨迹先验证 10 Hz，接地 FPM／G 保持现有高频短窗；观测数据共享，覆盖层开关不改变记录。处理暂停、时间跳变、回放、连续起落和换机。
- [ ] **P2.3 风记录**：每 x 秒保存风速／来向、相对飞机及跑道的侧风／顺逆风，先用 1 秒做开发验证，正式默认值待测。保存来源、实际时刻和有效性，区间峰值依赖更高频的真实观测，不能凭插值补出阵风。
- [ ] **P2.4 有界缓冲与写盘**：按块追加临时数据，限制内存与单帧工作量，显式标记写入失败或受限状态；中断保留已提交块，不覆盖前段。第一阶段可人工结束，但不计为自动脱离功能完成。
- [ ] **P2.5 即时快照**：接地分析、录制结束和保存成功为独立状态；即时弹窗固定截止时刻、后台持续采集，最终视图显示后续评分变化。
- [ ] **P2.6 自动存档恢复／低高度载入**：将“穿越 2500 ft”与“载入时已在 2500 ft 以下”作为两条启动路径。载入后首个有效空中样本先暂存，确认进近后保留这些样本，不要求重新爬高或再次穿越阈值；记录实际起始高度、起始原因、覆盖范围和缺段。加载状态未稳定时不采信占位零值，确认窗口不得漏掉随后真实接地。自动保存本身不重置会话；恢复、时间回退及瞬移才触发连续性检查。
- [ ] **P2.7 恢复记录与评分验收**：有匹配会话标识和可靠连续性证据的已提交块才关联续录，间隙仍标注；不假设模拟器存档保存了插件内存。反复读同一存档／回退重飞生成新尝试，禁止把上次存档点之后的轨迹接到新飞行上。测试 1500／500／50 ft 空中载入、加载后立刻接地、已在地面滑跑／停机位载入、短窗不足、无可用历史块和保存卡顿；证据不足的项目显示不可评估，不能补算虚假接地或把缺段本身计作扣分。

完成条件：所采位置、操纵、动力和风记录共享时间轴，30 分钟以上录制测得内存／写盘表现，暂停不计时间，弹窗不截断记录，异常结束有原因。低高度载入可录制实际可得区间，记录“正常结束”与“全阶段数据齐全”分开显示。

## 第三批：易读报告与末尾完整数据层

依赖 P2 的格式和写入流程；报告结构从 P0.1 即纳入设计。

- [ ] **P3.1 固定最终文件顺序**：①版本／机模／机场／会话与完成状态；②接地指标、阶段与最终等级、滑跑／风摘要；③沿用原有 100 ft 拉平及接地短窗的节选表；④必要的算法说明／数学复核；⑤完整记录数据层作为最后一部分。
- [ ] **P3.2 明确节选标识**：前部每个节选区明确标注 **“完整记录见末尾”**；英文为 “Full recording at the end of this report”。节选不代替完整数据，未录到 100 ft 段时说明原因，不截取其他区间冒充。
- [x] **P3.3 自描述的数据层**：尾部用稳定的开始／结束标识、格式版本、字段／单位／来源说明和分段数据表保存 2500 ft 至结束的全轨迹、操纵／动力、风及事件。字段语义不依赖中文／英文标题；均有时间戳，缺失值有明确表示，源切换事件可追踪。
- [ ] **P3.4 顺序与完整性**：现有可选数学复算附录移到完整数据层之前；采集时写分块临时流，最终按“前部报告→完整数据层→结束标识”流式组装并原子提交。不能先把海量数据写前面再整体读回内存搬运；完成标识只在尾部数据成功提交后成立。
- [x] **P3.5 解析兼容**：新解析器优先依据尾部格式标识读取完整记录，前部仅作为展示摘要，禁止把两套表合并成重复时间点。旧报告维持原解析路径；尾部损坏／截断明确提示，可显示有效摘要或已验证片段，但不伪装成完整报告。
- [ ] **P3.6 两个分析器同步**：完整数据并入原 100 ft 图表，提供统一时间轴缩放、横向浏览和风选项；真实路线、输入源和降级事件同步定位。长表按需展开／分页，曲线按视区简化绘制，保留评分所用原始值。
- [ ] **P3.7 验收**：新旧格式、中英报告、数学附录开关、100 ft 缺段、尾部截断和超长报告；TXT 的完整数据始终在最后，网页同一会话不重复计点，节选可追溯到完整记录。

排版改变解决可读性，不会自动缩小文件。容量通过字段去重、按不同频率分表、分块写盘控制；不为压缩而删掉已承诺的完整采样点或引入必须联网读取的依赖。

## 第五批：滑跑评分与完整覆盖层

- [ ] **P5.1 指标与影子判定**：实际横向偏差、持续时间／距离、有效左右摆动，先输出候选证据；去噪不覆盖原始记录。
- [ ] **P5.2 评分窗口与合并**：按最终标定规则处理转弯；当前只累计高速影子证据，不识别出口；触地点、弹跳和滑跑事件去重，统一幂等计算最终等级。
- [ ] **P5.3 标定与启用**：用正常／异常样本确认阈值及误报，记录规则版本后启用降级；风作为复盘证据，不未经验证自动抵扣评分。
- [ ] **P5.4 完整覆盖层**：在第一批摇杆组件基础上补齐油门／逐发动机 N1、显示开关、大小／颜色／透明度、布局保存与恢复；普通模式可独立使用，调试模式增加来源诊断，不成为覆盖层的唯一开启条件。
- [ ] **P5.5 实时曲线评估**：固定容量缓存验证 G 值曲线，区分瞬时 G 与接地稳健 G；是否纳入首版依据实机性能结果。

## 主要改动位置

| 区域 | 本轮动作 |
| --- | --- |
| `StarLux_LMM_v1.1.9.lua` 的 `LMM_CONTROL_REFS`、主更新循环、设置读写 | 逐轴来源、统一观测、调试选择、风序列、录制状态和新设置 |
| `LMM_UI_119/` 及主脚本兼容 UI | 贴边按钮、摇杆诊断组件、来源选择、既有设置／记录窗口复用 |
| 主脚本机场几何及评分区域 | 跑道投影、低速结束、滑跑指标和等级合并 |
| `build_landing_log_payload`、增量写入、日志管理／解析 | 前部摘要与 100 ft 节选、尾部完整数据、分块提交和历史兼容 |
| 两个 HTML 分析器 | 新格式解析、去重、摘要／全程切换、风与输入源同步复盘 |
| `tests/`、发行脚本与文档 | 数据源／状态／格式场景，长记录性能，新增文件入包及实机检查记录 |

新增核心代码优先隔离为小模块或既有命名空间子表，避免继续扩张接近一万行的主脚本及 Lua 顶层局部变量数量。沿用现有测试入口，核心场景可新增独立测试文件；不得为了通过检查而取消旧落地算法回归。
