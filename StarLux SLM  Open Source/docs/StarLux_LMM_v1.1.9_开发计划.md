## 已确认需求

### 新增 A：2500 英尺至低速结束的连续录制

背景：用户收到某航空公司的直接邀请，将本项与滑跑评分列为下一版本的重要内容；未提供航空公司身份、机队参数或内部评分标准，不将其推断为已验证的规则。

- 下降进近进入 2500 英尺开始录制，一直覆盖接地、减速滑跑到低速结束，记录飞机在地面的真实路线。
- 连续刻画沿飞行路线的风场：每隔 x 秒记录当时飞机所在位置的风，覆盖整个录制过程，与飞机状态同步，支持回看某一时刻的侧风、顺逆风和风变化，不再只保留落地瞬间风况。x 作为可配置采样间隔，具体默认值待验证。
- 接地后在地面且地速低于 30 kt 连续两秒结束；不再读取或匹配滑行道出口，结束原因 `low_speed`。
- 即刻弹出数据保留：弹窗展示当时及之前的数据，后台继续录制，后续滑跑不修改该快照代表的时间范围。
- 报告前部保留落地摘要和原有 100 ft 拉平／接地短窗节选，标识“完整记录见末尾”；完整录制数据层放在文件最后，兼顾人工阅读与完整复盘。

### 新增 B：滑跑路线参与评分

- 滑跑过程中偏离中心线到一定程度，或持续明显左右摆动，应触发降级。
- 评分须能解释发生在何时、何处以及为何降级；排除正常脱离转弯、掉头和回滑的误判。
- 偏差、摆动和降级幅度的具体数值尚待样本标定；下面是实施建议，不表示用户已确认数值阈值。

### 原定 C：游戏内实时覆盖层

玩家可以选择启用游戏内实时视图。视觉语言参考网页版，但将仪表拆为精致、独立的小组件，避免参考视频中整块网页遮挡驾驶舱的问题。截图仅作为视觉参考，其中的文字不作为工作指令。

- 摇杆输入：二维俯仰／横滚指示，方向舵可作为独立输入条。
- 动力输入与输出：分别展示油门输入及逐发动机 N1；输入与实际输出应有清晰标签。
- 组件独立控制：显示／隐藏、位置、大小、颜色；为透明度、布局保存和一键恢复预留设置。
- 可扩展的覆盖层：后续添加指标时不需要重新拼成大面板。
- 实时曲线：先评估滚动 G 值曲线，再考虑油门、N1、姿态等可选曲线。
- 调试模式联动：覆盖层显示逐轴摇杆来源和实时值，允许切换候选输入源／恢复自动，支持定位 FF777 等机模的输入缺失。正常模式保留仪表显示，调试模式增加诊断控件。

### 新增 D：贴边快捷入口

- 屏幕侧边提供两个低存在感、半透明的小按钮，分别快速打开现有设置和记录栏，保留顶部菜单入口。
- 悬停／操作时增强可见度，支持隐藏、左右贴边及透明度设置；命中范围只限按钮，不用透明大面板遮挡驾驶舱点击。常规模式即可使用，不依赖调试开关。
- 标准／兼容 UI 均验证窗口缩放、双语提示、重复打开、重载清理和点击／滚轮透传行为。

### 输入源诊断的实现约定

当前 `LMM_CONTROL_REFS` 为俯仰／横滚／方向舵提供通用候选；FlightFactor 专用 provider 是 N1 适配，不能据此认定摇杆已适配。FF777 的来源需实机验证，不预先猜定私有 DataRef。诊断显示路径、类型／下标、原始／归一化值、有效性及观察到的变化；区分有效居中和来源失效。

来源选择按轴生效，覆盖层和记录器共用同一观测结果。切换只改变读取路径，不写操纵值；按时间记录来源事件，只影响后续样本，不改写历史。手动源失效明确显示缺失，自动回退留痕。默认会话有效，允许显式保存机模配置；关闭调试隐藏控件但不隐式切源，换机／重载重新验证。舵面和动画值不能无标识地冒充驾驶员输入。

现有 `resolve_input_sources` 会把选中值复制到主候选字段，新实现须把候选原始数据与选择结果分开。先交付通用诊断框架，再用 FF777 动作和记录对照完成适配验收。

2. 完成摇杆、油门、N1 三类仪表，统一比例、字体、留白和配色；常规显示时尽量减少操作控件，编辑布局时显示拖动与缩放手柄。
3. 增加组件开关、主题色与透明度、布局保存、恢复默认；评估锁定布局和多屏边界处理。
4. 用固定容量缓存验证实时 G 曲线，明确采样频率、时间窗、纵轴、暂停／回放与断点行为；根据实机性能决定是否纳入首版。

## 覆盖层实现约束与待验证项

- 复用已有操纵与发动机数据适配；缺失数据标记不可用，不以 0 代替。N1 的来源、单位和发动机编号必须明确。
- 现有落地轨迹采集有阶段限制；覆盖层若用于全程飞行，须独立设计观测采样生命周期，不能直接假设现有落地缓存持续更新。
- 实时 G 曲线显示的瞬时载荷与报告的稳健接地 G 不同，需要清楚区分。
- 覆盖层开关不影响采集、评分和报告保存；连续录制与滑跑评分可以扩展报告格式及最终等级，但保留历史日志兼容。限频采样、固定容量显示缓存与可关闭绘制，避免长航程内存增长。
- 研究现有 SDK 440 UI 的复用方式，以及旧版 UI 的降级范围；隐藏组件是否停止绘制、拖动是否抢占驾驶舱操作、分辨率变化及帧耗时需要实机验证。
- 不在没有数据源和性能证据时承诺全部机模、VR 或多屏行为。

## A 的实现建议：录制、出口与报告

### 1. 独立录制状态与时间基准

建议状态为 `IDLE → APPROACH_RECORDING → TOUCHDOWN_CAPTURE → ROLLOUT → LOW_SPEED_FINISH → COMPLETE`；复飞进入 `GO_AROUND`，中断进入 `INCOMPLETE`，下一次进近创建新尝试 ID。弹跳仍属于同一次接地过程，连续起落不能把两次落地串成一个报告。`landing_complete` 保留接地分析语义，新增录制状态及文件写入状态。

2500 ft 暂按下降进近的离地高度理解，作为待确认的产品口径。当前名为 `radio_alt_ft` 的变量实际由 `y_agl_m` 转换，不应直接标成真实机载无线电高度。记录地形 AGL、MSL 及高度来源；机场标高相对高度可用于复盘校准，但不得悄悄切换触发基准。下降确认加短预录缓冲，保住越过 2500 ft 的样本；在 2500 ft 以下载入时从首个有效样本开始，标记前段缺失，不补造数据。地形起伏跨阈值不反复创建会话，短暂改平不按复飞结束。

连续录制保存时间戳、经纬度、高度及来源、地速、航迹／机头方向、地面状态、姿态、载荷、操纵和发动机数据，附逐通道有效性标记。文件保存模拟时间戳；网页以实际录制起点为 T+0，接地事件显式标记，旧 100 ft 表按接地时刻对齐。计时采用经暂停／回放检查的模拟时间，使用实际样本间隔；暂停重置两秒低速计时，时间倒退、瞬移或大段数据空缺不拼接成有效连续证据。

#### 自动存档恢复与低高度载入预案

2500 ft 是正常录制起点，不是必须经历的解锁条件。除正常下降跨阈值外，增加“载入时已低于阈值”的补启动路径：待位置、高度和空地状态有效后，先暂存空中样本，确认是进近再保留为本次录制起点。不强制重新爬升到 2500 ft，也不要求载入当帧就在下降；确认前短暂改平不丢掉有效样本，需与起飞爬升区分。加载占位数据和瞬移不进入真实接地判断，短确认窗口中发生的真实接地仍需保留事件。

例如在 800 ft 恢复且没有可用前段时，报告显示“本次从 800 ft 开始记录；2500–800 ft 段未记录”。保存实际起点、触发方式、已知缺口和观测覆盖率；只有可靠信号时才写明“自动存档恢复”，否则写“低高度载入／中途开始”。缺失的轨迹、操纵和风不以零值或插值填补。前部 100 ft 节选照常使用实际采到的部分；从 50 ft 开始则明确节选不全。

自动保存动作本身不结束或重置当前录制，保存造成的采样卡顿按实际缺口记录。读档／插件重载不等于插件状态已恢复：只有本地已提交数据块的完整性、会话标识及时间／位置／机模连续性都能验证时才关联续录，仍保留断点；仅机型和机场相同不足以合并。检测到回退重飞或不能证明连续时新建尝试 ID，保留旧记录，绝不连接上次读档点之后的“旧未来”，也不覆盖旧评分。

若存档已经在地面，只凭当前地速不能还原接地：有可信恢复状态时可继续对应滑跑记录；否则最多提供明确标记的手动地面片段记录，不制造一次落地或接地 FPM／G，也不把停机位载入识别为着陆。未观测到首触地时以片段起点计时，标为“片段时间”，不得冒充触地 T=0。

评分按数据覆盖分项处理：完整观测到接地计算窗口仍可给出接地结果；短窗或滑跑前段不足的项目标记部分可评估／不可评估，不把缺段本身作为扣分。已观测到的异常证据仍可展示；缺少关键项目时不得把局部结果包装为完整着陆总评。脱离后可以显示“录制已结束，前段缺失”，录制终止状态与数据完整性分别存储，尾部完整数据层表示本次所有已采样数据，并不暗示一定覆盖了 2500 ft 全阶段。

### 2. 真实跑道参考

仅复用目标机场跑道行与来源缓存，保留选定方向的两端真经纬度、宽度和准确触地点；每点投影为沿跑道距离和左正右负偏差。删除滑行网络解析及出口遍历。几何迟到不阻止两秒结束，生成接地摘要时仍可写入 `LMM_RUNWAY`，网页据此投影已经录到的进近及滑跑点。

### 3. 低速完成规则

接地后 `ground == 1` 且 `GS < 30 kt` 连续两秒结束。逐帧检查截止条件，不依赖 10 Hz 采样边界；不写入截止点之后的样本。再次达到 30 kt、离地、暂停、数据间隙则重置。正常低速结束与前段缺失／数据完整性分别显示，不声称已完成跑道脱离。

### 4. 即时快照与最终记录分离

采样器持续写入同一录制会话；报告读取指定修订号的不可变快照。即时弹窗标注“接地阶段结果／滑跑仍在录制”，截至弹出时刻已经完成的统计可用，后续事件只进入新修订。最终视图明确给出接地等级、滑跑评估和合并后的最终等级，用户能看出为何与早期快照不同。

保存分两层：保留接地阶段可查看的报告；新增按会话分块追加的连续数据，低速结束后生成最终报告并原子替换对应入口。记录 `session_id`、格式版本、修订号、录制状态、结束原因、阶段区间和评分规则版本，日志管理器按会话合并展示，不产生看起来重复的落地。采集、弹窗、写入失败分别处理，只有最终文件成功关闭／提交后显示保存成功。重载、退出或断电恢复只能恢复到已提交块，明确数据缺口。

新解析器对旧日志缺失的滑跑字段显示“未记录／不可评估”，不填 0、不改旧等级；继续保留原拉平／接地字段及短窗报告。已打开的独立网页是导入时的快照，首版用显式重新载入最终文件更新，不假设浏览器会自动追踪本地文件变化。

2026-09-21 明确最终 TXT 排列：基本信息与状态 → 落地指标／阶段及最终评分／滑跑和风摘要 → 100 ft 节选 → 算法说明与可选数学复核 → **完整记录数据层（最后）**。前部节选区标注“完整记录见末尾”，英文用 “Full recording at the end of this report”。没有有效 100 ft 片段时显示缺段原因。

末尾完整数据层包含轨迹、操纵／动力、风、阶段及来源切换事件，使用独立格式版本、开始／结束标识和稳定字段标识；通过共同时间戳关联，不依赖自然语言标题。完整数据是新解析器的数据来源，前部节选不得重复并入。截断或损坏必须标记不完整，不能退回节选后仍声称全程可用。

录制过程中按块保存临时流，结束时先输出可读前部再逐块拼接完整数据，成功提交后才标记完成；不得为调整布局把全文件一次读入内存。把数据放末尾只解决可读性，大小通过分表、字段去重和适当频率控制，不能因此删除承诺保留的完整样本。网页沿用原 100 ft 图表及仪表区域，通过同一时间轴缩放、横向浏览、100 ft 聚焦及全程播放显示完整过程；不另建完整记录面板。原始长表按需展开。

### 5. 风场时间序列与影响复盘（新增）

- **覆盖与间隔**：从 2500 ft 录制开始持续到本次录制结束，使用同一会话及模拟时间轴，每隔 x 秒保存风样本。建议先以 1 秒作为开发验证起点，提供采样间隔配置；该数值尚未确定为正式默认值。记录配置值、实际采样时间及数据来源更新情况，低帧率时不补造中间风样本；暂停不推进采样，回放和数据断点不拼接。
- **采什么风**：目标是飞机当时位置的局地风，不以机场 METAR、天气设定层或落地瞬间风况代替整段记录。保存风速、来向、来源、有效性、位置／高度与同刻飞机方向；优先验证可用的机旁环境风源，现有仪表风源可作为明确标注的备选。垂直风、阵风等扩展通道仅在来源及语义验证后纳入，缺失值不写成零。
- **描述相对作用方向**：统一真北／磁北和风的来向约定后，计算相对飞机机头方向的顺逆风、左右侧风分量；跑道确认后另提供相对跑道方向的分量。分别保存参考方向及符号约定，避免飞机正常转弯造成的分量变化被误标为环境风突变。方向均值用矢量计算，避免 359° 与 1° 被平均成 180°；静风时方向可标为无意义。
- **保留间隔内变化**：固定 x 秒样本之外，复用观测循环中有效且足够频率的风数据，增量统计区间均值、峰值及峰值时刻、有效覆盖率；明显变化可额外保留事件点。区间统计与瞬时值分开存储，不能只每 x 秒读一次再声称捕获了间隔内阵风。峰值来自源实际可观测的数据，不能补出源未提供的变化。
- **联合回放**：分析器增加风速、侧风、顺逆风曲线及风向箭头，与路线、横向偏差、姿态、G 值和操纵使用同一个时间游标。悬停或播放到任意时刻，展示最近有效风样本的时间差，并区分采样值、插值和区间峰值；跨缺口不插值。即时弹窗只统计快照截止时刻之前的风，最终报告保留完整序列与阶段统计，旧日志显示“未记录风时间序列”。
- **影响量的口径**：首版量化当时风速、相对风分量和变化幅度，同时展示飞机响应，帮助判断风与偏移／摆动的对应关系。仅凭风序列不能精确分离操纵、机体动力学等因素，不能声称“某次偏移有多少百分比由风造成”。本项先作为复盘证据；若后续要做风影响模型或风况评分修正，需要独立标定和规则版本，不自动增减既定滑跑评分。

验收覆盖恒定风、侧风增减、方向跨 0°、短时风变化、静风、飞机转弯而环境风不变、来源失效／低更新率、暂停与间隔变更。不同 x 下应明确显示可观测精度的差异，旧接地风字段继续兼容。

## B 的实现建议：评分可解释、可复算

### 1. 在跑道坐标中计算实际路线

以落地跑道方向建立局部米制坐标，计算每个有效位置的纵向进度 `s(t)` 和带符号横向偏差 `d(t)`。保存左右方向约定、跑道宽度和几何来源；使用经纬度位移或有效地面速度方向计算航迹，不把侧风下的机头方向当成实际路线。地景方向使用真北；与机模磁航向比较前必须统一基准。

### 2. 分开检测持续偏离与左右摆动

| 指标组 | 建议记录 | 判定重点 |
| --- | --- | --- |
| 偏离中线 | 最大绝对偏差、按实际时间加权的 RMS／P95、超限持续时间与行驶距离、相对跑道半宽的比例 | 使用幅度加持续性，区分定位毛刺与真实偏离；严重越界单独保留证据 |
| 左右摆动 | 去噪后的有效峰谷、峰峰值、交替反向次数、时间／距离间隔，航迹摆幅作辅助 | 设置中心死区和最小幅度／间隔；轻微修正和单次转入出口不能按连续摆动处理 |
| 数据质量 | 有效样本覆盖率、最长间隔、位置跳变、几何置信度、被排除区间 | 证据不足不处罚，也不显示为已通过该项 |

先将分米级／米级测量噪声与机模参考点运动评估清楚，再标定死区和低通参数；原始点保留，平滑只作用于分析副本。按时间而非点数计算统计，防止低帧率或变采样率改变评分权重。

当前未启用滑跑降级。影子指标仅累计 GS ≥ 30 kt 的连续地面段，保留已经发生的高速偏差；低速转弯不累加新候选。最终评分窗口和阈值继续以标定证据为准，不把低速截止规则包装为正常脱离识别。

### 3. 统一合并等级，避免重复处罚

保留接地基础等级，触地点中线、弹跳和滑跑规则输出带事件 ID 的评估结果，再由统一函数计算最终等级。建议同一偏离事件跨越触地与滑跑时只按同类最严重结果合并，独立事件是否累计及累计上限作为可版本化规则明确下来。计算必须幂等，不能每帧或每次解析报告再降一次。

先以“只记录指标及候选原因”的开发模式收集样本，再启用正式降级。现有 7／15 米仅用于旧触地点规则；滑跑阈值应结合跑道宽度、速度阶段、机型数据质量和邀请方提供的训练样本标定。每条降级输出起止时间、路线位置、指标、阈值、有效持续时间及规则版本，报告可回放定位，不只显示一个最终颜色。

## 性能与结构优化

- **采样分层**：复用每次观测读取的数据；连续轨迹先以 10 Hz 做基线，接地速度／G 短窗保留现有高频采样。远端进近若要降至 5 Hz，必须先验证事件和输入细节损失；不按 UI 帧率采集、不补造丢帧样本。
- **风记录独立限频**：风的 x 秒输出间隔与轨迹采样、UI 刷新解耦；区间统计用固定大小累加器，按块写入同一会话，避免重复读取同一 DataRef 或给每个轨迹点复制整套风统计。
- **缓存用途分开**：覆盖层曲线用固定长度环形缓存；整段录制用有界分块缓冲加渐进写盘，不能用滚动覆盖悄悄丢掉 2500 ft 开始的前段。10 Hz 连续 30 分钟为 18,000 点，以该规模测量 Lua 表开销、文件大小和写入耗时。
- **采集帧只做有限工作**：数值数组／复用样本槽减少临时 table；评分累计量按新样本增量更新，P95 等较重统计在快照或结束时分批算。到达结束条件不能一次生成整段巨大字符串。
- **机场解析按需完成**：保留已有索引、预读和帧预算，仅使用真实跑道参考；不解析滑行网络或搜索出口。
- **网页按视区绘制**：长轨迹分段载入，曲线按像素宽度保留极值降采样；地图可简化绘制折线但保留触地、异常、出口等锚点。展示简化后的点不得反向参与评分。
- **共享观测、独立消费者**：录制、接地算法和覆盖层复用数据适配结果，各自掌握生命周期；隐藏覆盖层只减少绘制。评估、导出和 UI 不互相改变状态。
- **控制模块规模**：现有主脚本接近一万行且已有 Lua 5.1 顶层局部变量限制提示；新增录制／几何／评分优先隔离成模块或既有命名空间子表，再接入主更新循环。若新建源码目录，发行脚本、清单和安装器包验证需同步覆盖。

性能验收记录新增功能前后的采样／几何／评分／写盘帧耗时 P95／最大值、内存高水位、丢样数和磁盘积压；预算根据目标低配实机确定，不提前承诺未经测量的固定帧率。写盘跟不上时必须显式记录受限状态，不能无限积压或阻塞接地分析。

## 开发顺序与验收场景

1. **建立样本与契约**：固定高度及位置参考、状态、格式版本、评分证据结构；保留现有 1.1.8 接地计算作为对照。向邀请方收集目标机型、典型机场、正常／异常轨迹及期望等级，但采集框架开发不等待阈值全部确定。

4. **验证低速结束**：无机场网络、29.9／30／30.1 kt、两秒边界、重新加速、弹跳、暂停及间隙。
