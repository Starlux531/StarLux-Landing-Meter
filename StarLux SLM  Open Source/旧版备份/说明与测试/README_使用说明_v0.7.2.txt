StarLux 落地率插件 v0.7.2 使用说明
================================

安装
----
将以下内容放入：
X-Plane 12/Resources/plugins/FlyWithLua/Scripts/

- StarLux_LMM_v0.7.2.lua
- LMM_Settings.cfg
- LMM_Log 文件夹（内含实飞测试样本，可按需保留或删除）

如果安装过旧版，请移走旧版 Lua 文件，避免两个版本同时运行。

打开设置窗口
------------
在 X-Plane 菜单中依次打开：
Plugins > FlyWithLua > FlyWithLua Macros > StarLux Landing Meter | Open Settings

也可以在 X-Plane 的键盘或摇杆设置中搜索并绑定命令：
starlux/lmm/open_settings

可用设置
--------
1. 落地数据窗口显示时机：分析完成后立刻 / 地速低于 30 kt 时
2. 显示时长：30 秒 / 60 秒 / 120 秒
3. 屏幕位置：九宫格位置选择
4. 窗口布局：横向 / 竖向
5. 背景透明度：25% / 50% / 100%
6. 测量调试信息：开 / 关
7. 5 秒预览：检查当前弹窗位置和样式

所有修改会立即保存到同目录下的 LMM_Settings.cfg，重新启动后仍然有效。

落地记录
--------
插件加载时会在 Lua 文件同目录创建 LMM_Log 文件夹。
每次有效落地会采集最多约 0.35 秒的第一次起落架压缩数据，
随后把速度分析、冲量分析和最终评分分散到不同更新帧执行。
选择“立刻”时，数据窗口会在最终结果就绪后显示，
约 3 秒后识别落地机场，并在约 8 秒后生成一份独立的 UTF-8 TXT 文件。
文件生成成功后，游戏内会额外显示“落地详细报告已生成”提示。

记录内容包括：
- 落地时间与总体评价
- 机型、落地机场、机场名称与推算跑道号
- 触地前三分钟内确认的实际降水、跑道摩擦状态、判断来源与道面提示
- 触地前 250 毫秒物理速度第 25 百分位（FPM）、80 毫秒旧算法值、仪表 VVI 对照值与最终过载（G）
- IAS、TAS、GS
- 迎角、横滚角、磁航向
- 风向、风速和相对风
- 原始 G、垂直投影 G、冲量等效 G、可信度、采样质量与评分阈值
- 本次使用的弹窗时机、位置、布局与透明度设置

跑道号根据触地磁航向推算，当前版本不区分平行跑道的 L/R/C。
TXT 文件名包含机场和跑道号，例如：LMM_ZGNN_05_2026-07-22_20-30-45.txt

评分标准
--------
Nice 轻柔接地（深绿色 #14803D）：FPM ≤ 100，G ≤ 1.20
Stable 稳定扎实落地（深蓝色 #12529E）：FPM ≤ 250，G ≤ 1.50
Attention 需注意（深橙色 #C7850F）：FPM ≤ 300，G ≤ 1.80
UNSTABLE 重着陆（深红色 #B81A1F）：FPM > 300，或 G > 1.80

FPM 与 G 分别判断，最终取较严重的等级。G 曲线产生的冲量会与物理垂直速度变化交叉验证；
持续冲击可保留较高可信度，单帧尖峰或采样不足会降低可信度并采用更保守的结果。

低于 1500 英尺后，插件每 5 秒读取一次实际机身降水和跑道摩擦等级。
跑道摩擦等级明确表示湿滑时，Nice 窗口提示“道面湿滑，注意摩擦力”；
实际降水连续两次达到 5% 时，Nice 窗口提示“持续降雨，道面可能湿滑”。

隐私说明
--------
插件不会联网，也不会主动上传飞行数据。
安装包中的 LMM_Log 内容是作者明确打包的实飞测试样本。

故障排查
--------
如果设置或日志无法保存，请检查 X-Plane 目录的写入权限，并查看：
X-Plane 12/Log.txt
